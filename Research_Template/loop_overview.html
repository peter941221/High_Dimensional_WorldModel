What You Run (WezTerm)

Run the loop in one pane, and (optionally) tail its logs in another pane. The loop is not restricted to the template folder; it runs at the repo root and can edit any tracked files in this workspace.

cd "C:\AI Projects\Fun Stuff\High_Dimensional_WorldModel"

:: or limit iterations

:: tail logs in another pane
.\Research_Template\monitor_research.bat
  • start_research.bat defaults to unlimited iterations (equivalent to -MaxIterations 0).
  • Use -NoLiveOutput if you want the loop quiet, then rely on the monitor.
  • If a run is already active, start_research.bat attaches the monitor instead of failing.

Streaming Model Output

The loop always captures Codex stdout/stderr into per-step files. When live output is enabled, the loop tails those files to the console so it feels like chat. If you see long quiet periods, it usually means the researcher is running a long command (training/eval/pytest) that prints rarely.

  • Live output: default when you run start_research.bat.
  • Quiet run: pass -NoLiveOutput and use the monitor.
  • Monitor: monitor_research.bat tails both the JSONL trace and the latest researcher stderr log.

Auto-Commit Rules

Each iteration can auto-commit. This is designed to keep progress incremental and reproducible.

  • Primary selection: files_touched from the researcher JSON, committed even if the repo started dirty.
  • Fallback: git status delta for new/changed paths.
  • Hard exclude: Research_Template/runtime/.

If you want auto-push, set auto_push in the template JSON.
